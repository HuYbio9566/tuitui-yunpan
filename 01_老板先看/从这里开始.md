# 云盘工具项目｜老板从这里开始

这是一份给项目负责人的中文入口。你不需要看懂代码文件。

## 这个项目是做什么的

这是 360 企业云盘的 AI 工具原型项目。它把云盘里的文件变成可以摘要、问答、核验、审阅和整理的工作结果。

## 你只需要看哪里

1. `02_项目管理/项目总览.md`：看项目现在是什么状态。
2. `02_项目管理/当前任务.md`：看现在正在做什么、还有什么没决定。
3. `02_项目管理/版本台账.md`：看产品版本和设计版本，避免混在一起。
4. `03_设计资料/截图/`：看页面截图。
5. `https://github.com/HuYbio9566/tuitui-yunpan`：看 GitHub 项目。

## 哪些文件不用打开

- `.js`：网页功能代码。
- `.css`：网页样式代码。
- `.test.js`：自动测试代码。
- `.git`、`.vercel`、`.nojekyll`：电脑和网站发布使用的系统文件。
- `05_网站程序（电脑使用）/`：网站程序，电脑运行需要，老板不用打开。

## 当前网站入口

打开项目根目录的 `index.html` 就可以进入工具中心。它会自动打开 `05_网站程序（电脑使用）/` 里的网站。
