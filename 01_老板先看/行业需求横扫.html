高度依赖已有知识 / 文件的工作，
以及其中仍主要靠人工完成的信息处理

从现实社会中的工作形态出发，不讨论具体技术方案，只回答两个问题：哪些工作高度依赖已有知识与文件？其中哪些工作至今仍有大量“人肉信息处理”环节？

PART 02

其中，哪些工作仍主要靠人工完成信息处理？

进一步筛选后，重点不是“知识要求高”，而是人的日常工作本身是否仍在大量执行找、读、筛、比、填、核、写、传等信息动作。

不是所有知识型工作，都属于“人工信息处理重”

  • 外科医生：专业知识要求极高，但核心价值发生在诊疗与操作。
  • 飞行员：规程与知识很多，但主要价值是实时判断与操作。
  • 高级设计师：会参考大量资料，但核心仍是创造与决策。
  • 厨师：高度依赖经验，但主体不是文档型信息处理。

真正“人肉信息处理重”的典型状态

  • 一天大量时间都在打开文件、搜索资料、切换窗口。
  • 重复阅读、摘录、复制、比对、核验和整理。
  • 最终成果多为报告、意见、表格、材料或审批结果。
  • 人的价值很大一部分消耗在“处理已有信息”本身。

KEY JUDGEMENT

不是“人工最重”就最适合 Agent

真正优先的机会，是那些同时具备知识复杂、跨文件处理、任务可拆解、判断有依据、结果可交付的工作场景。

THREE TYPES

三类机会形态

A · 知识工作流 Agent招投标 / 法务合同 / 审计 / 医药注册
B · 知识协作型 Agent咨询研究 / 政府材料 / 项目管理 PMO
C · 智能流程增强保险理赔 / 工程造价
WHY A FIRST

A 类更像真正的 Agent 主战场

它们不仅需要“读懂知识”，还需要持续调用资料、按规则判断、组织下一步动作，并最终形成可以直接交付的结果。

优先验证：招投标 / 法务合同 / 审计 / 医药注册
